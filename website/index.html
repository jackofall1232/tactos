Features

A clipboard that actually works for you

tactos replaces the drawer full of single-purpose utilities with one fast, offline app — and its spine is the smartest clipboard on Android.

Clipboard timeline

Unlimited, searchable history of everything you copy. Pin it, favorite it, file it into categories. Nothing expires unless you say so.

Knows what you copied

Every clip is type-detected on your device: URLs, colors, JSON, email addresses, IPv4 and IPv6, phone numbers, plain text.

Acts on it

A URL becomes a QR code — generated offline. A color converts HEX⇄RGB⇄HSL. JSON validates, beautifies, minifies. One tap.

Zero permissions

The APK requests none — not even internet. There is no code path by which your clipboard could leave your phone.

Yours

No ads. No accounts. No subscriptions. MIT-licensed open source — so it stays that way.

Material You

Dynamic color on Android 12+, a calm teal-and-amber palette below. Light and dark, always.

Privacy

Privacy isn't a setting. It's the architecture.

Your clipboard is the most sensitive stream of text on your phone — passwords, addresses, one-time codes, half-written messages. tactos is built so it physically cannot betray that.

  • Zero permissions. The manifest declares none — including no INTERNET. Android itself guarantees the app can't phone home.
  • Everything stays on your device. The timeline lives in a private local database in the app's own storage. No cloud, no sync you didn't build.
  • Sensitive clips are never stored. When another app marks a clip sensitive — a password manager, a 2FA app — tactos keeps it out of plaintext history.
  • No analytics. No crash SDKs. No trackers. Not "minimal telemetry" — none. The dependency list is short, open, and auditable.
  • Open source — verify it yourself. Don't take this page's word for it: read the manifest on GitHub. MIT-licensed, end to end.

This website plays by the same rules: one HTML file, no scripts, no fonts, no cookies, no trackers. Open your browser's network tab — this page is a single request.

How capture works

Honest about the clipboard

Since Android 10, background apps can't silently read your clipboard — and that's a good thing. tactos works with the platform, not around it, so capture is layered and every rung is optional:

1

Share to tactos

Send anything from any app's share sheet straight into the timeline. Works everywhere, today, with no special access.

2

Open tactos

Whenever the app comes to the foreground it reads the current clipboard and files it — copy, switch over, done.

3

Add manually

Paste or type anything into the timeline yourself. Notes, snippets, things you want to keep findable.

Planned — not shipped yet

Background auto-capture

An opt-in accessibility service that does nothing but clipboard capture, behind a plain-language disclosure you can decline. tactos stays fully functional without it.

Install

Sideload it in a minute

No store account needed. tactos ships as a plain APK you can install and verify yourself.

Sideload the APK

  1. On your phone, download the latest APK from the releases page (v0.1.0 coming soon — CI debug builds available meanwhile).
  2. Tap the downloaded file. Android will ask you to allow installs from your browser or files app — allow it (you can revoke this afterwards).
  3. Tap Install. Done — no account, no setup, no network.

Or build from source

One command from a clean clone:

git clone https://github.com/jackofall1232/tactos
cd tactos
./gradlew assembleDebug

The debug APK lands in app/build/outputs/apk/debug/. What you build is exactly what you read.
